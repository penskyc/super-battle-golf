# Super Battle Golf — Site Vision

## 1. Overview

The official website of the **Super Battle Golf League (SBGL)** — the world's premier full-contact, explosives-permitted golf competition. This site presents the sport as a legitimate, highly competitive real-world athletic pursuit.

**Tone:** Authoritative sports league. Think NFL.com or UFC.com, not a gaming fansite.
**Audience:** Sports fans, athletes, spectators, sponsors, media

---

## 2. Core Message

Super Battle Golf is a real sport. Professional athletes compete on specially designed Battle Courses using regulation golf equipment and approved tactical munitions. The SBGL governs all official competition.

---

## 3. Tech Stack

- Pure HTML5 / CSS3 / Vanilla JavaScript
- No frameworks — lightweight, fast, deployable anywhere
- Shared navigation and footer via included HTML patterns
- Responsive (desktop-first, mobile breakpoints at 768px)
